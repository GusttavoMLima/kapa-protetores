# Assets do Figma

Imagens originais exportadas do arquivo de design Kapa.

- `dog-face-shiba.png`: rosto ilustrado de cachorro.
- `pet-faces-collection.png`: conjunto com quatro rostos de pets.
- `dog-aggressive.png`: cachorro em postura agressiva.
- `kapa-pet-mark.png`: símbolo laranja de cachorro e gato.
- `dog-face-happy-large.png`: rosto grande de cachorro feliz.
- `dog-happy-sitting.png`: cachorro feliz sentado.
- `dog-face-corgi.png`: rosto ilustrado de corgi.
- `dog-happy-full.png`: cachorro feliz de corpo inteiro.
- `dog-avatar-happy.png`: avatar compacto de cachorro.
- `cat-face-black-large.png`: rosto grande de gato preto.
- `cat-avatar-black.png`: avatar compacto de gato preto.

Os arquivos `app-icon.png` e `splash-screen.png` são exportações dos frames finais do Figma e também alimentam os assets principais configurados pelo Expo.
